👨‍💻 **Solução:** Solução Multiplataforma (Web e PWA) para gestão de ativos, movimentação, inventário e estoque. Empresa: Maior grupo brasileiro de aluguel de ativos de TI e serviços agregados. Solução Multitenant.

  
💼 **Atuação:** Definição e desenho de arquitetura, apoio na ideação e levantamento funcional, modelagem, construção do produto (backend e frontend), validação, implantação, geração de manual, treinamento de usuários. Criação de rotina de migração de dados do sistema legado à partir de exportação em Excel.

🛠️ **Stack/Infra:**

* 📲 Ionic (multiplataforma) com REACT
    
* 📦 Node / Adonis.js / Typescript
    
* 🎲 MS SQL
    
* ⚙️ Windows + IIS
    

✅ **Resultados / Geração de Valor:** Redução de tempo no processo de movimentação de ativos, processamento manual de movimentações em planilhas eliminado, processo de inventário mais seguro e assertivo, economia em todo processo, adequação a *compliance* e exigências das empresas contratantes e parceiras, geração de dados para integração com ERP e BI.
