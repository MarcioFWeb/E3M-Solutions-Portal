👨‍💻 **Solução:** Solução Web e Mobile Híbrida para gestão dos dados, contratos e informações de clientes da maior empresa de aluguel de equipamentos e serviços de TI do Brasil. Dados dos contratos, chamados, indicadores e sla´s, atendimentos, arquivos do contrato/cliente diversos, histórico do contrato.

  
💼 **Atuação:** Definição e desenho de arquitetura, gestão de consultoria externa que desenvolveu parte da solução, ideação e levantamento funcional, modelagem, construção do produto (backend, frontend e web), ajustes e features da solução mobile base entregue por consultoria, validação, implantação, geração de manual, treinamento de usuários. Criação de rotina de migração de dados do sistema legado com carga/migração de grande base de arquivos.

  
🛠️ **Stack/Infra:**

* 📲 React Native + EXPO (mobile ios e android)
    
* 🖥️ React
    
* 📦 Node / Adonis.js / Typescript
    
* 🎲 MS SQL
    
* ☁️ Azure (blob storage)
    
* ⚙️ Windows + IIS, Centos Linux, Apache, Apple Store e Google Play
    

  
✅ **Resultados / Geração de Valor:** Redução de custos com encerramento de contrato de ferramenta paga (e limitada), integrações necessárias personalizadas economizando tempo em processos (erp, itsm, bi), comunicação personalizada com cada cliente, aumento do nível de satisfação dos clientes, compliance e transparência dos contratos, informações relevantes para os clientes entregue de forma real-time com notificações, comunicação personalizada com cada cliente.
