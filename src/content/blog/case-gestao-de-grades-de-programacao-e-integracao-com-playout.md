👨‍💻 **Solução:** Aplicação Web interna de alta precisão para planejamento, edição e gestão das grades de programação de TV e rádio, com integração direta aos sistemas automatizados de playout e transmissão.

💼 **Atuação:** Engenharia de software e desenho de arquitetura de alta confiabilidade, mapeamento das regras de negócio do departamento de programação, construção de interface web dinâmica com controle de horários/blocos e barramento de integração com os servidores de playout.

🛠️ **Stack / Tecnologias:**
* 🖥️ Frontend Web dinâmico e reativo
* 📦 Backend / Microsserviços para orquestração de grades
* ⚙️ Barramentos de integração com automação de playout de vídeo/áudio
* 🎲 Banco de dados transacional com alta integridade temporal

✅ **Resultados / Geração de Valor:** Eliminação de reconciliações manuais entre planilhas e o sistema de exibição, sincronização em tempo real das alterações de grade e confiabilidade crítica para a operação ininterrupta (24/7) da emissora.
